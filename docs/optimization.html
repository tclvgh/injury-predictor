optimization module

Model Optimization Module for Injury Prediction System.

This module provides functionality for optimizing machine learning models through hyperparameter tuning. It compares baseline models with optimized versions and calculates performance improvements.

class optimization.ModelOptimizer(x_train: ndarray, y_train: ndarray, x_test: ndarray, y_test: ndarray)

Bases: object

Optimizes machine learning models through hyperparameter tuning.

This class provides methods to train baseline models, optimize hyperparameters using randomized search, and compare performance between baseline and optimized models. It focuses on XGBoost regression models for injury prediction.
